# AuralFlow 双端功能补齐清单

> 原则：**先补齐功能，再做信息架构改版**。  
> 基准：桌面端为成熟参考；移动端对齐「能完成同样任务」，不照搬桌面布局。  
> 日期：2026-07-10

## 0. 已具备（不要重复造）

| 能力 | 移动端现状 |
|---|---|
| 播放历史 | 曲库 `history` 分区：播放全部 / 随机 / 清空 / 单曲删除；首页「最近播放」预览 10 首 |
| 每日推荐 / 私人 FM | 首页 mode 切换进入独立页 |
| 下载 / 本地 / 我喜欢 / B站合集 | 曲库分区 + 快捷入口 |
| WebDAV / 自定义音源 | 独立 Screen |
| 多源搜索 | `all/wy/tx/bili` + 联想词 + 结果缓存 |
| 歌单详情 | 播放全部 / 随机 / 定位当前 / 刷新 / 收藏 / 导入 |
| 播放页 | 队列、定时关闭、倍速、音量/静音、歌词、沉浸歌词、系统歌词浮层（Android） |
| 设置 | 音质、其他音频打断（暂停/降音量）、音效面板、歌词样式、缓存清理、账号、更新 |

## 2. 真缺口与增强（按优先级）

### P0 — 听歌主路径上的功能残缺

| ID | 缺口 | 现状 | 目标（对齐桌面能力） | 建议落点 |
|---|---|---|---|---|
| F01 | 播放页/沉浸歌词 **无音效入口** | `SoundEffectPanel` 只在设置 | 播放页可快速开关/调节音效（与桌面沉浸歌词一致） | `PlayerScreen` + `ImmersiveLyricsScreen` |
| F02 | 首页最近播放 **不能一键看全部** | 只 slice 10 首，无跳转 | 「查看全部」进入完整历史列表（可先跳曲库 history 分区） | `HomeScreen` + 轻量导航参数 |
| F03 | 专辑/歌手详情 **批量操作弱** | 有播放全部/随机，行内能力靠 SongList | 补齐与桌面同级的：播放全部态、随机、空态/失败态文案一致性；歌手页热门一键播放已有则补「下载/加歌单」可达性 | `AlbumDetailScreen` / `ArtistDetailScreen` |
| F04 | 列表行操作 **不完整暴露** | SongList 有喜欢/下载/加本地歌单，但部分详情页未强调 | 历史/推荐/专辑/歌手列表统一可：播放、喜欢、加歌单、下载 | `SongList` 使用处审计 |

### P1 — 管理能力与桌面齐平

| ID | 缺口 | 现状 | 目标 | 建议落点 |
|---|---|---|---|---|
| F05 | 本地音乐 **导入方式单一** | 基本只能扫设备媒体库 | 在权限允许下：扫媒体库 + 选文件/文件夹（或 SAF）+ 刷新；编辑元数据保留 | `localMusicService` / 曲库本地分区 |
| F06 | 下载管理 **目录/失败态** | 有列表、重试、删除、清空 | 展示保存位置、失败原因更清晰、默认音质与设置联动（改目录若系统限制则只读展示） | `DownloadScreen` / `downloadStore` |
| F07 | 沉浸歌词 **控制条偏瘦** | 有播放/歌词海报切换等 | 对齐桌面沉浸：译文开关、队列、倍速、音效入口（定时可次要） | `ImmersiveLyricsScreen` |
| F08 | 播放历史 **管理动作入口弱** | 曲库内有清空/删除，首页没有 | 完整历史页或分区顶栏：清空、编辑删除；与桌面 HistoryView 操作集对齐 | 可新建 `HistoryScreen` 或强化曲库 history |
| F09 | 每日推荐 **下载/加歌单** | 播放/随机/刷新有 | 行内下载、加喜欢/本地歌单与桌面一致 | `DailyRecommendScreen` + SongList |
| F10 | 数据清理 **语义对齐** | 缓存清理、清历史+缓存已有 | 文案与范围和桌面「清空播放历史与缓存」对齐，避免两套说法 | `CacheSettings` |

### P2 — 体验增强（非阻断）

| ID | 缺口 | 说明 |
|---|---|---|
| F11 | 搜索结果 **歌手/专辑非网易云** 详情限制 | 与桌面类似，非 wy 详情弱；可做降级播放列表而非硬挡 |
| F12 | 自定义音源 **搜索参与度** | 解析 URL 已有；是否进综合搜索需产品决策 |
| F13 | 歌单同步/转存进度 | 两端都有 transfer，移动端进度与失败重试展示可加强 |
| F14 | 播放页音质切换 | 设置有默认音质；播放中临时切换属增强 |
| F15 | 网格/列表视图（本地） | 桌面本地有网格，移动可后置 |

## 4. 验收口径（每项通用）

1. 桌面能完成的任务，移动端有明确入口且可走完  
2. 不依赖「先改 Tab 架构」才能用  
3. 有基础空态 / 加载 / 失败反馈  
4. 能复用现有 store/service，禁止平行造第二套状态  
5. 平台独占能力不强制 1:1 UI

## 5. 明确后置（架构改版阶段再做）
