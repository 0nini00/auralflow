# AuralFlow v0.9.0

自 v0.8.0 以来两条主线：**桌面端把沉浸播放页的三处缺陷修完并补齐入口**，**移动端做了一轮界面重构**（抽屉壳改 Stack、音乐库合单屏、底部栏与详情页重做）。桌面与 Android 同步到 0.9.0（Android versionCode 36）。

## 桌面 · 沉浸播放页

- **打开沉浸页后窗口拖不动**：根因是全屏层的 `position: fixed; inset: 0; z-index: 1800` 整片盖住了顶栏，而顶栏（`z-index: 20`）是全局唯一的窗口拖拽区，只能先退出再拖。现在由沉浸页根节点接管拖拽：空白处按下即拖、双击最大化/还原；歌词区（自身要用拖拽滚动）、底部控件条、浮层面板按区域白名单不接管，按钮/输入框也仍然优先。
- **曲名 / 歌手 / 专辑能被拖成蓝色选区**：全窗表面补 `user-select: none`。
- **进度条看起来变成三条**：焦点环是 `outline: 2px / offset 5px`，而它挂在一个 `opacity: 0`、高 24px、宽度 `100% + 48px` 出血的 range input 上，左右两边被裁掉，只剩上下两条与进度条同色的横线。改为点亮 1px 轨道本身，并把初始焦点交给播放键（`data-dialog-initial-focus`，`useDialogFocus` 本就支持这个约定），默认状态不再出现焦点环。
- **退出键从「更多」面板挪到右上角常驻**：34×34，`top: 14px`，右侧与页面留白对齐（1360 宽窗口实测 60px）；「更多」面板里不再有退出项，保持唯一入口。
- **主播放控件常显**：之前整组默认 `opacity: 0`，打开沉浸页看不到播放键。现在只有右侧工具组（歌词工具 / 播放列表 / 桌面歌词 / 更多）默认隐藏，并在 hover、自身获得焦点、面板打开时浮现，`pointer-events` 同步，不会留下看不见的可点区域。

## 桌面 · 桌面歌词

- **首句与末句也能居中**：整篇滚动时首尾会被容器边界夹住，永远回不到当前行那一行。前后各加一段留白（高度按实测行高与行距算，扣掉一格 gap），当前行位置取自该行的真实 `offsetTop`。实测行高 36 / 行距 8 / 3 行窗口下，第 1、6、11 行的可见偏移都是 44px（= 行位 1 × 步长 44）。
- **「动效强度」真正影响滚动**：原生 `behavior: 'smooth'` 时长不可控，等于这项设置对滚动无效。改为 rAF 自绘补间，时长 = 320ms × 强度（reduced 176ms / normal 320ms / enhanced 400ms）；关掉动效或系统要求减少动态时直接到位。

## 移动端 · 界面重构（阶段 0–4）

- **导航壳**：删掉抽屉（`AppHeader` / `DrawerContent` / `MainDrawerNavigator`，共 476 行），设置改为根 Stack 的独立屏；四个 Tab 换成 64px 标签栏 + 选中胶囊，迷你播放器浮在标签栏上方 6px，键盘弹出或无歌时整块收起。
- **音乐库合单屏五段**：歌单 / 本地 / 收藏 / 历史 / 下载用分段芯片切换，不再嵌套 TopTab；深链与首页快捷入口统一写 `librarySectionStore` 再切 Tab。歌单与收藏拆成 `PlaylistsSection`（938 行，含新建/导入/导出/链接导入与三个编辑弹层）和 `FavoritesSection`（199 行）。
- **我的页瘦身**：900+ 行降到 290 行，只留账号、快捷入口、服务与同步、设置，并新增「本周听歌」统计卡。
- **首页 / 搜索**：首页改 28px 大标题 + 「继续收听」卡 + 4 格图标快捷入口（未登录自动换成本地音乐/下载）；搜索空态改为「按风格浏览」8 格，点击发起真实搜索（没有热搜数据源就不伪造榜单）。
- **播放页与详情页**：沉浸播放页固定深色调色板、返回键改下滑语义、66px 品牌绿实心播放键 + 队列直入口；新增 `FloatingDetailHeader`（悬浮返回键 + 滚过封面后淡入实底标题栏），接入歌单/专辑/歌手/本地歌单四个详情页；设置首页 8 类压成 4 组行列表。
- **令牌与主题**：正文 14→15、标题阶梯 17/20/28、页面边距 16→20、`tabBarHeight 64`、`radius.xxl 28`；画布改暖中性 `#F3F3EF` / 深色 `#0B0F0D`，新增 `primaryInk`，自定义强调色自动压到 4.5:1 对比度。

- 沉浸页右侧工具组的 **hover 浮现**没有像素级验证：无头浏览器里 CDP 派发的鼠标移动不会触发 `:hover`；同一规则组里的「焦点」和「面板打开」两条路径已实测。
- 桌面歌词首尾留白的**观感**建议真机再看一眼，几何已对齐。
- 移动端队列的「当前曲独立钉住卡」未做，仍用行高亮表示当前曲。
- `@react-navigation/drawer` 已无引用，但依赖仍在 `package.json`，留待依赖清理。

## 升级

桌面端覆盖安装即可，设置与缓存不受影响；已有 0.8.0 及以上版本会通过内置更新清单提示升级。Android 端直接覆盖安装新包（versionCode 36 > 35），本地曲库与歌单数据保留。
