# AuralFlow v0.10.0

自 v0.9.0 以来的**移动端**一轮配色与设置打磨：主题色可自选（8 个预设 + 调色盘）、实心按钮统一深绿、竖屏播放页亮度复核、设置二级页细节与返回层级修复。

> 桌面端本次**没有功能改动**，安装包只为版本号同步重出；桌面用户升级与否不影响使用。

## 移动端 · 主题色

- **默认强调色换成深行动绿**：`#3BD877`（亮绿）→ `#0D7A42`。旧值走 `migrateAccentColor` 自动迁移，已安装用户不会停在亮绿上。
- **8 个预设色**：默认绿 `#0D7A42` / 松针 `#146B52` / 湖蓝 `#1D6FA5` / 靛青 `#3B4FA8` / 暮紫 `#6B4BA8` / 赭橙 `#A9531A` / 莓红 `#A8324F` / 岩灰 `#4A5450`。
- **调色盘**：新增 `ThemeColorPicker`（HSV 饱和度/明度选区 + 色相条 + Hex 输入）。拖动时只更新本地预览，松手才写回主题 store，避免每帧落盘 AsyncStorage。
- **对比度策略改了**：`buildPrimaryInk` / `buildActionFill` 以前无条件压深，现在「够 4.5:1 就直接用你选的颜色」，只有不足时才压深/提亮——选什么就看到什么。

## 移动端 · 配色统一

- 新增 `palette.actionFill` / `onActionFill`：实心按钮与实心选中芯片统一深绿底 + 白字（5.4:1）。覆盖 `Button` 的 `brand`、迷你播放器播放键、竖屏播放器播放键、首页「继续收听」、歌单编辑确认键、私人 FM 大播放键、新建歌单、启动重试键。
- 全站绿色**文字 / 图标 / 选中态文字**统一到 `primaryInk`，不再出现同屏「荧光绿文字 + 深绿按钮」两种绿。
- **竖屏播放页亮度复核**（用户反馈进度条与播放键过亮、其他按键显暗）：进度条固定用播放器 dark palette、轨道改中性半透明白、填充 70% 主题色、滑块 12→8px 且改 `primaryInk`、高度 4→3；播放键改 66px `actionFill` 深绿实心 + 白图标，去掉绿色光晕。
- 新增 `IconButton` 的 `tone="accent"`：原来 `tone="primary"` 映射到 `primaryText`(深色)，在深色播放页几乎看不见；播放模式/喜欢/悬浮歌词/睡眠定时改用它。

## 移动端 · 设置

- 二级页：`SettingsCard` 圆角 12→16 且裁切内部底色、卡片间距 12→16、标题 18→17 与全局 `PageHeader` 一致、卡内行统一 12px 水平内边距；账号卡 VIP 角标改深橙 `#B45309`、ID 行改 `textMuted`。
- 返回层级修复（用户反馈）：从「我的」直接进外观/播放/歌词等二级页，返回时会先回「全部设置」。现在 `settingsCategoryStore` 新增 `fromSettingsHome` 来源标记——「我的」直达的二级页返回直接回「我的」，「全部设置」进入的返回先回设置首页。顶栏返回与 Android 返回拦截共用同一判断。

## 验证

- 移动：`tsc --noEmit` 0 错误；`eslint src App.tsx` 0 错误；**539 例**通过（新增 `settings-navigation` 2 例）。
- 桌面：代码与 v0.9.0 一致，沿用 v0.9.0 的验证结论（`tsc` 0 错误、62 文件 / 493 例、CSS 解析 14/14、`vite build` 成功）。

## 已知未做

- 调色盘的**观感**（尤其自定义颜色的深色主题对比）建议真机再确认一次；对比度自动压深只在不足 4.5:1 时触发。
- 桌面端无功能改动，本轮桌面安装包仅版本号变化。

## 升级

桌面端覆盖安装即可（功能与 v0.9.0 相同）。Android 端直接覆盖安装（versionCode 37 > 36），主题色、歌单与本地曲库数据保留；旧的自定义强调色会自动迁移到新色值。
