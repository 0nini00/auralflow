# AuralFlow v1.0.3

桌面端重写了动态背景的着色器、补上自绘下拉；移动端修掉「启动被网络校验拖住」和「千首列表滚动掉帧」。桌面与 Android 同步到 1.0.3（Android versionCode **52**）。

## 桌面端 · 沉浸背景重绘

- 液态渐变与极光光幕换掉噪声格点，改成低频色流：原有的方块与竖条消失，暗部色带用抖动压掉，线性空间混合更自然。
- 灰白封面会借用主题强调色的色相，不再退化成一片灰雾。
- 修复渲染器监听错对象：只观察根节点（封面色与强调色都写在根上），切歌后背景色现在会跟着封面变，同时不再每帧空转取色。

## 桌面端 · 自绘下拉

- 新增 Select 组件：方向键、Esc、点空白、滚动都能关闭——原生 select 在 Tauri 窗口里做不到这些。
- 设置页的「沉浸式播放背景」「歌词字体」「音质偏好」三处原生 select 全部替换；每日推荐的日期下拉并入同一组件，删掉重复实现。

## 移动端 · 启动与列表

- 启动不再被账号网络校验阻塞：带 Cookie 的状态校验（弱网最长 15 秒）移出启动关键路径转后台，本地凭证先渲染界面。
- 歌曲列表增量挂载批量 100 → 25，千首级列表滚动不再周期性出现长帧。
- 播放快照进度落盘间隔 10s → 30s，减少大队列序列化对 JS 线程的挤占。
- 播放历史只在真实发生迁移 / 规整时回写磁盘，正常加载不再整份序列化。

## 其它

- 登录失效错误类型统一、深度链处理修正。
- 播放器 store 测试扩展；Android 签名守卫改为按任务图判断，多 ABI 构建不再误报缺失。

## 验证

桌面 721 项测试、移动 881 项测试、core 与双端类型检查通过。
