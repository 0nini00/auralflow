# AuralFlow v1.0.1

移动端把两种动态播放背景合并为一个「柔光色域」，播放器内的弹层收成同一套外壳；桌面端保留原有两种背景不变。桌面与 Android 同步到 1.0.1（Android versionCode **50**，本轮重建重新上传移动端安装包）。

## 移动端 · 柔光色域

- `液态渐变` 与 `极光光幕` 合并为单一 `柔光色域`，选项收敛为「纯色 / 封面氛围 / 柔光色域」。
- 低频色团随时间缓慢漂移，不含高频噪声：内部分辨率降到 360×640 后放大依然平滑，填充率与发热明显低于原实现。
- 颜色同时取封面色与主题强调色，灰白封面也能得到有颜色的背景，不再退化成灰雾。
- 输出叠加抖动，抑制 8bit 渐变在暗部的色带；颜色过渡时间 0.7s → 1.2s。
- 旧存档里的 `liquid` / `aurora` 自动迁移到 `柔光色域`，不会因为值失效而清空背景。

## 移动端 · 弹层统一

- 新增共用弹层外壳：统一遮罩、20 圆角、拉手、标题行、安全区与进出场动画（220ms 进 / 160ms 出），高度上限 78%。
- 倍速、音量、睡眠定时、播放设置、封面菜单改用同一套外壳；播放设置从居中卡片改为底部弹层，封面菜单从居中警告框改为底部弹层。
- 评论与队列的顶部圆角对齐到共用取值。
- 睡眠定时原先没有高度上限，小屏上会超出屏幕；现限制在 85% 并在内部滚动。
- 弹层配色跟随应用主题：浅色主题下不再沿用播放页那份固定的深色面板。

## 桌面端

- 保留 `液态渐变` / `极光光幕` 两种背景，本轮未改动桌面渲染与设置。

## Android · 从其它应用打开音乐和音源

- 文件管理器「用其他应用打开」可选择 AuralFlow 打开常见本地音频及 JS/JSON 音源文件，兼容 `file://`、`content://`、常见大小写扩展名及通用文本/二进制 MIME。
- 对没有文件名后缀的文档 URI，读取提供方的真实文件名和 MIME 后决定播放音频或导入音源；不支持的文件明确提示。
- 外部音频经原生模块读取曲目信息后直接播放，不把临时访问授权写入本地曲库。冷启动等待应用就绪后再处理，连续打开时过期解析结果不会覆盖新请求。
- Android 12 及以上补齐多点文件名和带点目录的后缀匹配；文件关联不接管 HTTP/HTTPS 链接。
