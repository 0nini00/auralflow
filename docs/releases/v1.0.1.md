# AuralFlow v1.0.1

双端新增液态渐变与极光光幕两种沉浸式播放背景，移动端将常用播放操作收敛为单行五键，并补齐从文件管理器打开音乐和音源脚本的入口。桌面与 Android 同步到 1.0.1（Android versionCode **48**）。

## 沉浸背景 · 双端新增两种动效

- 新增「液态渐变」「极光光幕」，与原有封面背景并列选择；桌面外观设置和播放页更多菜单共用同一份配置，移动端歌词设置与背景选择面板也保持同步。
- 两端复用 core 中同一份着色器，颜色跟随封面或主题强调色；背景程序不加载远程脚本、图片或视频资产。
- 暂停播放、页面隐藏或退到后台时停止持续动画；系统开启「减少动态效果」时保留静帧。关闭页面释放渲染资源，图形初始化或上下文异常提供明确提示。
- 移动端打开操作弹层时暂停背景动画；旧「氛围色背景」开关迁移为对应的封面氛围或纯色模式，保留原有选择。

## 移动端 · 五键底栏与右上角更多

- 底部固定为「播放模式 / 上一首 / 播放暂停 / 下一首 / 队列」一行五键，320dp 宽度下不换行；保留原进度区、触觉反馈与播放模式提示。
- 顶部保留关闭按钮、原歌名和歌手，右侧统一为更多入口。喜欢、悬浮歌词、评论、睡眠定时、播放设置、背景效果及原有下载、歌单、MV、分享、相似歌曲操作集中到菜单中。
- 菜单先关闭，再打开下一弹层，避免 Android 连续弹层的触摸冲突；喜欢、悬浮歌词和睡眠定时显示当前状态。
- 保留原封面、分页与歌词布局；修正浅色全局主题下深色播放器按键颜色过暗的问题，播放与加载图标使用播放器自身配色。

## Android · 从其它应用打开音乐和音源

- 文件管理器「用其他应用打开」可选择 AuralFlow 打开常见本地音频及 JS/JSON 音源文件，兼容 `file://`、`content://`、常见大小写扩展名及通用文本/二进制 MIME。
- 对没有文件名后缀的文档 URI，读取提供方的真实文件名和 MIME 后决定播放音频或导入音源；不支持的文件明确提示，不再全部按音源脚本读取。
- 外部音频经原生模块读取曲目信息后直接播放，不把临时访问授权写入本地曲库。冷启动等待应用就绪后再处理，连续打开时过期解析结果不会覆盖新请求。
- Android 12 及以上补齐多点文件名和带点目录的后缀匹配。Android 7–11 的此类路径仍依赖发送方提供正确或通用 MIME；文件关联不接管 HTTP/HTTPS 链接。
