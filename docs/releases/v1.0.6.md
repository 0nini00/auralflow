# AuralFlow v1.0.6

这一版补齐了音乐云盘的上传与删除，桌面和 Android 两端同步到 1.0.6（Android versionCode **55**）。同时带上了 1.0.5 之后的移动端下载目录、网页登录、本地扫描与播放队列修复。

## 音乐云盘（双端）

- 新增云盘上传：支持一次选择多个音频，先检查云端是否已有相同文件，再直传 NOS 并写入歌曲信息。
- 上传使用原生流式读取与直传，大文件不进入 JS 内存；支持实时进度和取消。
- 新增云盘歌曲删除：行内入口，确认后删除云端记录并刷新列表。
- 上传协议模型下沉到 `@lx/core`，桌面与 Android 共用同一份字段、文件名清洗和 LBS 地址拼装规则。
- 移动端「音乐云盘」入口移到「我的」页快捷入口，文案与实际能力一致。

## 移动端

- 新增应用内网易云网页登录：登录成功后自动读取并验证 Cookie，不再必须手动复制。
- 下载位置支持选择系统文件夹（SAF）：设置行改成紧凑样式；切换到外部文件夹后只保留一份文件，不再额外占一份应用内副本。
- 修复本地扫描缺歌：同一首歌的多条下载记录不再互相覆盖；旧记录指向的私有文件被移动后，会按下载文件名前缀从当前文件夹找回。
- 修复下载页布局：完成列表改为紧凑两行，操作按钮固定高度；修复巨大空白卡片与竖长按钮。
- 修复切歌时进度条从上一首位置回退到开头的动画，改为直接归位。
- 播放队列行只保留歌名和删除按钮；播放页底部新增喜欢、评论、下载、悬浮歌词、更多五个快捷操作。
- 搜索「全部」页只跟随单曲分页，不再出现四个加载更多和零计数统计卡。
- 修复队列有歌但没有当前曲时，「下一首播放」误替换整条队列的问题。
- 修复本地扫描单文件失败拖垮整次扫描、封面不刷新、扫描进度缺失。
- 修复播放页辅助操作行样式、下载位置设置行高度、网页登录弹层与应用现有头部/按钮规范不一致。

## 桌面端

- 云盘页新增上传与行内删除；上传由 Rust 负责 MD5、LBS 解析和 NOS 流式直传，进度回传前端并支持取消。
- 修复「下一首播放」在无当前曲时的队列替换问题，并补充操作反馈。

## 验证

移动端 1080 项测试、桌面端 878 项测试全部通过；双端 TypeScript 检查、桌面 ESLint、Rust `cargo check` 与 Release 构建通过。Android ARM64 与 armeabi-v7a 使用正式证书签名，桌面安装包与 updater 签名已生成。

真实网易云账号的云端上传/删除仍需在双端登录后实测，接口属于客户端私有链路，可能受账号风控或服务端策略影响。
