# AuralFlow v0.7.1

上一版把本地曲的**歌词**补上了，封面还是一片空白。本版让桌面端在没有封面时自动去平台匹配，并且**当次播放就能看到**。

## 本地曲封面自动匹配（桌面端）

- **触发点在起播，不在歌词页**：本地曲一开始播放就补一次封面（歌词匹配成功时还会顺路提前触发一次）。只挂在歌词匹配上的话，不打开歌词页、或歌词命中缓存/内嵌词的曲目永远不会补——而所有起播路径（下一首 / 上一首 / 单曲循环 / 会话恢复）都收敛在 `play()`，触发点不会漏。
- **封面地址取官方接口，不自己拼 picId**：用被采用候选的网易歌曲 id 调 `/api/song/detail` 取 `album.picUrl`。三种取法都联网实测过：官方接口 4/4 都能取到图（200 / `image/jpg`），gdstudio 网关 pic 同一批 4/4 连地址都不返回，唯一返回过的一条在图片主机是 `NoSuchKey` 死链（把歌曲 id 当文件名拼出来的假地址）。所以官方为主、网关退为兜底；两者都取不到只记一条日志，不落盘，下次播放仍会重试。
- **落盘后当场回填**：封面写进该曲既有的封面缓存键后，立即贴到正在播放的曲目上（同时回写播放引擎），不必切走再切回来。缓存命中是零网络；有内嵌封面或手动指定封面的曲目在第一个 `await` 之前就返回，一张请求都不发——**手动指定的封面永远优先**，自动化不会覆盖它。
- **封面不参与任何主流程的成败**：搜索、取地址、落盘的异常与挂起都不阻塞起播与歌词；查询期间切歌不会把旧封面贴到新歌上。
- 搜索与判定抽成 `localMediaMatch.ts`，歌词与封面共用同一份规则（歌词那边行为未变）。

## 桌面

- 版本同步到 0.7.1。
- 顺带修正文档里封面缓存的过时描述：此前写「song-covers 不限量」，实际是 512 MiB、按 mtime 淘汰。

## Android

- 版本同步到 0.7.1（versionCode 27）。**本版 Android 侧没有代码改动**，APK 重打只为版本号与 Release 一致：应用内更新是拿 `releases/latest` 的 tag 与自身版本比较的，若 Release 是 0.7.1 而包装出来的版本名仍是 0.7.0，用户会被反复提示更新。

## 测试与验证

- 桌面前端：60 文件 531 例全过（封面匹配新增 3 组 61 例，既有 470 例零回归）。
- 双端类型检查、`@lx/core` 类型检查、移动端 lint 通过；`pnpm check:all` 退出 0。
- 联网实测：官方 `/api/song/detail` 的 `album.picUrl` 4/4 可取（200），真实封面对象加 `?param=600y600` 返回 200（1.06MB → 254KB，正是应用实际会下载的那条）。
- 本版未改移动端、`@lx/core` 与 Rust 代码，这些测试套件未重跑。

## 边界与未做

- **网易侧没有这首歌时补不到封面**：原唱被下架的都属此类（例如周杰伦《晴天》、吴亦凡《Bad Girl》，网易只剩别人的翻唱重传）。歌词走 LRCLIB 不受影响；封面暂时没有第二来源——QQ 音乐源经网关搜索实测所有查询都返回 400，做不了兜底。
- **旁挂图片（`folder.jpg` / `cover.jpg` / 同名图片）仍未支持**：移动端早就支持，桌面端只读内嵌封面与手动指定。它不受平台下架影响，是本地库最稳的封面源，列为下一步。
- **未做真机人工验收**：验证到自动化测试与联网接口实测为止，实际播放中的封面显示仍需人工确认。
