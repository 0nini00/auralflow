# AuralFlow v0.7.4

这一版把「多来源」从列表上的徽标变成一等公民：搜索结果可按来源筛选；同一首歌在多个平台的版本会一起进解析与下载候选链，解析失败自动尝试同组变体，还可以在「其他版本」里把本机首选 pin 住。本地曲这边，封面不再联网「猜」，歌词匹配改为可逐曲手动选择。另修跨源兜底三处缺陷与跨端 SSRF 校验分歧等多处问题。

## 搜索与多来源（双端）

- **来源筛选 chip**：搜索页单曲区新增「全部 / 网易云 / QQ」，纯客户端过滤已聚合结果、不触发重搜；没有对应来源时置灰；开始新搜索自动回到「全部」。播放队列使用过滤后的列表。
- **多来源版本进候选链**：解析与下载不再只看主条目——同组变体（网易云 / QQ 同名同曲）按打分排序进入候选链，主条目解析失败会自动尝试变体；降级接管成功时播放条会注记「已切换 QQ 音乐源」，换源不再无声无息。
- **「其他版本」菜单**：桌面搜索单曲行、移动端行操作菜单可查看该曲的其他来源版本（来源、歌名、歌手、时长），行尾星标可 pin 本机首选，重复点击解除。
- **判定规则收敛**：歌名 / 歌手规范化、同曲判定、变体分组与排序统一收归 `@lx/core` 的 `song-variant`（此前散在五处的拷贝实现），同曲容差统一为 5 秒。
- **修跨源兜底三处缺陷**：变体缓存此前只存最优一条，排序靠前者解析失败即整首判死（改为存完整候选数组）；音源脚本增删 / 启停后缓存未清（现在变更即清）；两端语义统一为「宁可降音质也不换版本」。

## 本地曲（双端）

- **封面只取文件自身**：内嵌标签 → 同目录 folder.jpg / cover.jpg / 同名图片，没有就显示占位图；整条联网封面匹配链路与其界面入口全部删除。既有的「手动封面」设置与 manual-covers 目录不再被读取（文件保留，封面回落到文件自身那张）。
- **歌词可逐曲选择**：「自动匹配 / 已选歌词 / 不要匹配」三态。选中某份歌词后永不联网再搜并显示来源；「不要匹配」只用内嵌标签与同目录 .lrc。入口在本地曲列表的操作菜单与沉浸歌词页。
- **改名 / 移动后仍能认回**：歌词选择按文件内容哈希留一份孤儿记录（桌面按 size+md5，移动复用已有 SHA-256），文件改名或移动后自动重绑；内容被替换则回落到自动匹配。
- 候选列表按匹配结论排序并标注来源、时长差与首行预览，但绝不隐藏候选，由用户自己判断。
- 顺带修：移动端「不要匹配」此前被空串吞掉、实际退回自动搜索的缺陷。

## 修复与内部清理

- **跨端 SSRF 对齐**：出站 URL 校验的文档网段断言与 JS 侧对齐到更严一侧，并新增 49 条跨端契约 URL 清单，JS 与 Rust 两侧各自断言同一批结论。
- **静默失败显式化**：桌面端启动失败会写日志与 stderr（此前直接静默退出）；托盘初始化、歌词窗位置落盘失败记 warn；媒体缓存容量守卫在启动时也执行一次。
- **封面写入按魔数白名单**：手动匹配封面与音频标签封面共用同一张图片魔数表，不再「认不出来就当 JPEG」写进音频文件。
- 去重复实现：桌面 6 处 shuffle / 导入标记拷贝收拢；移动端删掉与导航重复的底部标签模型与零引用的 wakelock 服务。
- 文档数字校正（测试计数、行数、缓存上限等，逐项以代码与实测为准）。

## 边界与未做

- 来源 chip 只过滤单曲列表，不影响「综合」区的其他聚合结果；筛选不触发重搜。
- pin 是本机行为，不参与 WebDAV 云同步；换设备需重新 pin。
- 下载在线曲时向文件标签写平台封面的路径不受本版改动影响。
- **仍未做真机人工验收**：验证到自动化测试与打包为止。装好后建议实测：搜索按来源筛选、其他版本 pin 与降级注记、本地曲手动选词与「不要匹配」三态。
