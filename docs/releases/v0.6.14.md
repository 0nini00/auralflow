# AuralFlow v0.6.14 — Windows

## 变更

- **任务栏缩略图恢复为系统默认的实时窗口画面**：Alt+Tab 与任务栏悬停里的缩略图现在和别的应用一样，是按窗口比例缩放的实时画面，不再是被替换的静态封面。此前预览用的 `DWMWA_FORCE_ICONIC_REPRESENTATION` 会让 Windows 优先显示我们提交的静态位图（即使存在实时表示），而静态位图只能按系统给出的最大尺寸出图，于是缩略图比其它应用小、也对不齐。
- 退役「封面预览」：设置项改名为「任务栏缩略图按钮」，三个按钮（上一首 / 播放暂停 / 下一首）保持不变；封面解码、位图组装、DWM 属性设置与缩略图消息应答的代码一并删除。前端不再需要查询本地封面缓存，也不再为封面落盘做延时补推。
- 保留 v0.6.13 的两项修复：缩略图不再黑屏（真实画面），以及音量合成器里显示为「AuralFlow + 应用图标」而不是「Microsoft Edge WebView2」。

## 下载与更新

- `windows-x64-setup.exe`：Windows x64 安装版（应用内自更新使用它）。
- `windows-x64-portable.exe`：Windows x64 便携版。
- `.sig`、`latest.json`、`latest-mirror.json` 为桌面更新签名和清单，普通用户无需单独下载。
- Android 最新仍为 v0.6.12；本版只包含桌面端改动，移动端更新入口在下一次 Android 发布时恢复。

## 验证边界

- Rust 侧 54 项测试、桌面前端 417 项测试、共享核心 137 项测试全部通过；类型检查通过。用例数比上一版少，是因为随封面预览管线一起删除了 11 个 Rust 用例与 17 个前端用例，并补了状态变化的替代用例。
- 缩略图观感（是否与其它应用一致、Alt+Tab 是否为实时画面）需要安装后人工确认：自动化测试覆盖不到 DWM 的实际渲染。
