# AuralFlow v0.6.7

## 桌面端

- 新增“设置 → 音源 → 启用 LX 自定义音源”总开关：新安装默认关闭，旧版已有音源保留开启，关闭保留脚本、排序和逐源设置。
- 总开关统一控制音源管理、取链、预加载缓存、测试、更新检查、弹窗和音源同步；内置音源、本地播放及普通歌单同步不受影响。
- 关闭后丢弃旧操作结果，重新开启不会复活之前的任务；总开关仅本机保存，云端同步不能将其重新开启。
- 修复关闭 LX 后音源同步等待仍阻塞歌单同步的问题；音源与普通同步分别互斥，防止未结束的旧上传与新音源上传乱序覆盖。
- 修复开关保存失败不反馈、旧失败快照覆盖新状态、数据恢复失败仍可启用等持久化边界问题。

## Android

- 版本同步到 0.6.7（versionCode 15），提供 arm64-v8a 与 armeabi-v7a 正式签名兼容包。
- 本轮未新增移动端功能；LX 总开关改动仅适用于桌面端。

## 安装包

- Windows x64 安装版与便携版。
- Android arm64-v8a、armeabi-v7a APK。
- 桌面自动更新清单包含安装包更新签名，保留直连与镜像入口。

## 边界说明

LX 开关是功能控制而非脚本安全沙箱。已经发出的远端请求不能撤回；关闭会停止应用侧等待，并阻止迟到响应写入本地数据。正在播放的歌曲及已经开始的下载不强行中断。
