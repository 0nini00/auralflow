# AuralFlow v1.0.7

本次更新调整双端播放背景，并修复 Android 本地音乐扫描。桌面与 Android 版本均为 1.0.7，Android versionCode 为 56。

## 桌面端

- 用 MyGo Music 烟雾背景替换液态渐变和极光光幕，旧选择自动迁移；封面背景仍可选择。
- 烟雾随封面取色，包含缓慢上升的雾层和漂浮微尘；暂停后渐停，窗口隐藏或启用减少动态效果时停止动画。
- 保留图形错误提示与上下文恢复，限制绘制帧率和分辨率；修复暂停末尾换封面时颜色停在过渡中间的问题。

烟雾算法改编自 egoist/mygo-music，来源、修改说明和 AGPL-3.0 许可证见 `desktop/third-party/mygo-music/`。当前未接入低音联动。

## Android

- 播放背景固定为柔光色域，移除封面背景选项及背景选择面板；旧背景设置在读取和保存时清理。
- 切歌期间保留已有背景配色，新封面取色完成后平滑过渡；加载下一首时也能完成颜色过渡。
- 移除竖屏播放器右上角的更多按钮，底部更多入口继续可用。
- 修复有效 AAC、损坏标签或旁挂歌词异常导致整次本地扫描失败的问题。歌曲基本信息保留，可选资料读取失败会显示具体警告。
- 系统媒体库、下载记录与手动导入按文件身份去重，保留已有曲库 ID、用户修改和下载文件归属。
- 区分文档提供方 ID 与系统媒体 ID，避免数字 ID 碰撞覆盖歌曲或写回错误的系统记录。
- 并发扫描共享一个任务；分支失败后停止接收进度，等待已启动的任务结束后再允许重试，避免失败后重新显示扫描进度。

## 安装包

- Windows x64：安装版、便携版，附应用更新签名与更新清单。
- Android：ARM64、armeabi-v7a，使用现有正式签名证书。
