# AuralFlow v1.0.4

修复桌面端网易云请求全部失败；桌面设置改为单一来源、多窗口即时同步；移动端修掉私人 FM 队列编辑失效和坏缓存文件卡死一首歌。底层把两端重复的逻辑收进共享核心。桌面与 Android 同步到 1.0.4（Android versionCode **53**）。

## 桌面端 · 修复

- 修复网易云请求全部失败：Tauri 的 JS 包与 Rust 插件版本错位。现在有契约测试比对两份锁文件，构建一律 `--locked`，这类错位不会再混进发布。
- 播放取链失败会显示具体原因，不再统一显示「未返回播放地址」；登录过期在播放时也能被识别。
- 跨源切换失败会报真实原因。

## 桌面端 · 设置与多窗口

- 设置只有一个来源：任何一处修改由后端落盘并通知所有窗口，在主窗口改歌词字号、对齐等，桌面歌词立即跟着变。
- 「恢复默认」的默认值只在后端定义一份。
- 设置读取失败时，设置页显示原因和重试按钮，不再用默认值顶上。
- 桌面歌词与迷你播放器不再加载整个播放器，只接收主窗口的播放状态，打开更轻。

## 移动端 · 修复

- 私人 FM 播放中在队列面板移除、拖拽歌曲，下一次切歌不再把队列还原。
- 磁盘上的缓存音频损坏时，重试会删掉它重新取链，不再让这首歌一直播不了。
- 存储损坏不再静默变成空数据：主题和 WebDAV 配置损坏会先备份再用默认值；下载记录、首选版本损坏时拒绝写入并提示。
- 自定义音源深度测试的超时提示不再显示「超过 0s」。

## 其它

- 网易云加密与请求拼装、云盘列表状态、自定义音源协议在两端共用同一份实现。
- 移除没有入口的心动模式与稍后播放暂存区。旧版本留下的心动模式播放快照会按普通队列恢复。
- 桌面后端约 45 处被丢弃的错误改为记日志。

## 验证

core 401 项、桌面 809 项、移动 949 项、Rust 107 项测试，双端类型检查与 lint 通过。
