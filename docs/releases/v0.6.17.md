# AuralFlow v0.6.17 — Windows

## 修复

- **修复播放会话恢复失效**（v0.6.16 新加的功能在实际使用中表现为「重启后什么都没保留」）。根因：启动时恢复音量会触发一次播放引擎的状态推送，而旧逻辑把引擎的空状态（`currentMusic: null`、`currentTime: 0`、`duration: 0`）无条件写回 store，把刚恢复的当前曲、进度、时长当场覆盖；队列其实已经恢复（`playback.json` 里 30 首都在），但迷你栏因为没有当前曲而整条隐藏，所以看起来「全丢了」。现在引擎里没有加载曲目时**不再参与**当前曲/进度/时长的同步（真正的清空路径 stop / clearQueue / 换曲仍在 store 侧显式执行），并补了两条回归用例覆盖「空状态不覆盖恢复结果」与「有曲目时仍照常同步」。
- **打开播放列表时当前曲居中**：桌面队列面板此前把当前曲贴在列表下沿（用户还得往上找），现在居中显示；移动端（v0.6.18）同样处理（此前贴在上沿）。

## 下载与更新

- `windows-x64-setup.exe`：Windows x64 安装版（应用内自更新使用它）。
- `windows-x64-portable.exe`：Windows x64 便携版。
- `.sig`、`latest.json`、`latest-mirror.json` 为桌面更新签名和清单，普通用户无需单独下载。

## 验证边界

- Rust 侧 56 项测试、桌面前端 435 项测试、共享核心 137 项测试通过；类型检查通过。
- 恢复链路的验证来自代码路径与用例（引擎空状态推送、写盘时机、读盘校验、恢复语义），**重启后的实际观感仍需人工确认**：队列与当前曲是否还在、进度条位置是否正确、按播放是否从上次位置继续。
