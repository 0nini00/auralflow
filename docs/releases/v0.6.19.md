# AuralFlow v0.6.19 — Windows

## 修复

- **歌词补回「作词 / 作曲 / 编曲」等元信息**(此前只有 tx 源正常,网易云源看不到)。
  根因:桌面端走的是网易云 eapi 歌词接口,它把这类元信息写成**富文本 JSON 行**
  (`{"t":0,"c":[{"tx":"作词: "},{"tx":"林夕"}]}`),而不是标准 `[mm:ss]`;解析器只认后者,
  于是这些行被整行丢弃 —— tx 源返回标准 LRC,所以一直完整。实测本机 284 条歌词缓存里
  有 213 条缺元信息,而同一批歌曲走另一个歌词接口能拿到 3–9 行。现在解析器会在进入各分支前
  把富文本行归一成标准时间戳行(逐字轨 yrc 里的同类行也会保留),并用整数毫秒换算时间戳,
  避免个别小数毫秒拼出非法时间戳把整行再次丢掉。用真实接口复验 8/8 首均完整保留。
- **主页的「右滑块 + 下滑块」消失**。根因:内容滚动区只声明了纵向滚动,横向的 `visible`
  被浏览器提升成 `auto`;卡片右缘「添加到」按钮的悬停提示自带 120px 宽的浮层盒子,越过内容
  右边界 24px,于是撑出横向滚动条,横向滚动条又占高度、再挤出纵向滚动条。实测隐藏该浮层后
  横向溢出 24px→0、水平滚动条 10px→0。现在显式禁用横向滚动,并让该按钮的提示气泡改为右对齐
  展开(朝左伸展,不再越界)。
- **「最近播放」全屏时不再右侧留白**。根因:网格用 `auto-fill`,会为放不满的列保留空轨道 ——
  2560px 下 9 张卡片摊在 13 列里,右侧空出 684px。改用 `auto-fit`,实测右侧间隙 684px→0;
  同时给卡片 240px 宽度上限,避免卡片只剩一两张时被拉伸成一块巨大的封面(实测 774px→240px)。
- **「听歌统计」全屏时铺满页面**(此前只占一半宽,右侧一片空白)。根因是视图写死了
  `max-width: 900px`。实测 1920px 下宽度 900→1556,2560px 下 2196。
- **导入更新后的音源会直接覆盖同名旧源**(以前会留下旧的一份,得手动删)。根因:导入只按
  「脚本内容完全相同」查重,同名的更新脚本被当成另一个源追加。现在同名源原位覆盖,保留你的
  启用状态、更新提醒开关与排序,并清掉旧脚本的能力清单与更新状态等重新测试。
- **沉浸式页面能看清歌词逐字滚动了**。根因:未唱与已唱只差一点透明度(0.76 与 0.98),
  在深绿背景上对比度只有 1.57:1,肉眼几乎看不出推进;而且行级渐变和逐字高亮会互相干扰。
  现在逐字行只由逐字高亮承担进度,未唱压暗、已唱提到纯白并加辉光,对比度实测 1.57→3.88。

## 下载与更新

- `windows-x64-setup.exe`:Windows x64 安装版(应用内自更新使用它)。
- `windows-x64-portable.exe`:Windows x64 便携版。
- `.sig`、`latest.json`、`latest-mirror.json` 为桌面更新签名和清单,普通用户无需单独下载。
