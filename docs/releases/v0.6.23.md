# AuralFlow v0.6.23 — Windows

紧急补丁版:修复 v0.6.19 起桌面端大面积 UI 样式失效。

## 修复

- **首页样式表括号缺失导致的大面积 UI 崩坏**(v0.6.19 / v0.6.21 均受影响)。
  根因:v0.6.19 编辑 `home.css` 的 `@media (max-width: 768px)` 块时,遗留了一行重复的
  `.af-home-recent-grid {` 选择器,并吞掉了 `@media` 的收尾 `}`——全文件括号 52 开 / 50 闭。
  构建产物中自该处起约 4100 行 CSS 被嵌进未闭合块(构建日志可见
  `css-syntax-error: Expected "}" to go with "{"`),浏览器按 CSS 嵌套把后续所有规则
  降级为 `.af-home-recent-grid` 的后代选择器,不再命中页面其余部分,表现为
  播放页 / 统计 / 设置等大面积样式失效。
  修复:删除遗留的重复选择器行、补回收尾括号。修复后括号 51/51 平衡,
  vite 构建无任何 CSS 警告;v0.6.19 的其余修复(auto-fit 铺满、卡片宽度上限、
  tooltip 右对齐、沉浸式逐字对比度)全部保留。

## 验证

- `home.css` 括号 51/51 平衡;`pnpm desktop:build` 无任何 CSS 语法警告。
- 桌面前端 453 项测试通过。

## 下载与更新

- `AuralFlow-v0.6.23-windows-x64-setup.exe`:NSIS 安装版(支持应用内自动更新)。
- `AuralFlow-v0.6.23-windows-x64-portable.exe`:便携版。
- 从 v0.6.19 / v0.6.21 升级:安装版可直接「设置 → 检查更新」,或下载 setup.exe 覆盖安装。
