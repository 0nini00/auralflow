# AuralFlow v1.0.0

第一个正式版。双端从「能用」收敛到「顺手」：播放历史按天浏览、真实收听统计、离线缓存、分页搜索，以及一轮覆盖双端的 UI/UX 与可访问性整理。桌面与 Android 同步到 1.0.0（Android versionCode **47**）。

## 播放历史 · 按天浏览

- 桌面端新增单日视图：顶部 `‹ 日期 ›` 前后翻，点日期开月历，只能选「今天及以前 + 确实有记录」的日子；「时间未知」的老记录单独分档。
- 历史改为**按天条目**：同一天同一首歌一条，跨天保留多次，不再被「每首歌最后一条」覆盖。
- 保留策略统一到 core：最近 **365 天 / 最多 4000 条 / 按整天裁剪**；时间未知单独 200 条预算。
- WebDAV 历史改为按条目往返，双端合并按 `key + 本地日` 求并集；上传只带最近 180 天 / 最多 2000 条，控制同步体积。
- 旧数据就地迁移；落盘同时保留旧字段，降级回旧版本不会把历史读成空。

## 收听统计 · 只计真实播放

- 双端接入真实收听会话：只累计前台连续推进的时间，跳转、暂停、缓冲不计入；同一会话 checkpoint 幂等。
- 移动端按 UTC 月使用 `AtomicFile` 独立存储，只写变更月份；单月损坏只跳过并提示，不再让整库永久读失败。
- 桌面统计页补 `loaded` 态，冷启动不再先闪「还没有播放记录」。

## 离线缓存 · 双端可浏览

- 设置 → 数据管理新增离线缓存库：浏览、搜索、播放、批量删除。
- 播放只校验目标曲，其它缺失项按磁盘实况跳过，不再因为一首被淘汰而整批失败。
- 桌面 `list_cached_audio` 单个文件元数据异常只跳过自身，整页不因一个坏文件报错。

## 搜索 · 分页与缓存

- 双端按分类独立翻页；音源忽略 `page` 时不再无限显示「加载更多」。
- 移动端首页直连空结果不再当成有效结果缓存 5 分钟，风控软拒时会继续走网关兜底。
- 搜索结果支持方向键 / Home / End 在行间移动焦点，Enter / Space 激活；Tab 仍可逐行离开。

## UI / UX · 双端整理

- **错误边界**拆成 inline / fullscreen：单个页面或右栏崩溃只废掉内容区，侧栏、顶栏、播放条仍可用。
- **切页复位滚动**：从长列表进设置不再停在半截；路由 chunk 加载补骨架屏。
- **破坏性操作**：桌面 11 处原生 `window.confirm` 全部换成跟随主题的共享确认框（焦点陷阱 / Esc / 危险色）；移动清空队列补二次确认。
- **撤销**：桌面/移动队列移除、双端搜索历史清空都支持 Toast 撤销；带撤销的提示停留 6s/5s，桌面悬停或聚焦时暂停计时。
- **侧栏收起 = 图标栏**：64px 保留全部导航图标，只隐藏文字与分组标题；无歌时播放条保留同高占位，首播不再跳 88px。
- **列表**：桌面历史/歌单行高与 CSS 对齐（52px），历史封面走缩略图并按需加载；移动行高常量改为 64，定位当前播放不再偏行。
- **加载与空态**：统计、收藏、本地扫描、首页排行榜都区分「加载中 / 空 / 失败」，不再先喊「没有数据」。
- **可访问性**：进度/音量/队列删除补焦点可见样式；搜索分类、来源筛选、播放设置步进、历史词删除等补到 44dp；关键文本限制字体缩放上限。
- **按钮族**：歌单详情迁到统一的 `PlaybackActionButtons`，补回随机播放，窄屏允许换行。
- **歌单归属**：移动端统一判断自建/收藏歌单，歌曲操作入口收敛到 `useWyPlaylistSongOptions`，`loading/error` 拆成独立字段避免互相覆盖。
