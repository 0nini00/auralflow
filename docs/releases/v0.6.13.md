# AuralFlow v0.6.13 — Windows

## 修复

- 修复切换应用（Alt+Tab）与任务栏悬停时缩略图显示为黑块的问题。缩略图尺寸参数的高、低 16 位此前解析反了，提交给 DWM 的位图总会有一个维度超限被拒收（`E_INVALIDARG`），而在强制图标式表示下系统又不会退回窗口快照，于是只剩黑块；现已按 SDK 定义取「高位=最大宽、低位=最大高」。
- 无封面（未播放、封面解码中、推送被拒）时改用窗口大图标兜底应答，避免这些时刻同样出现黑缩略图。
- 修复系统音量合成器里把本应用显示为「Microsoft Edge WebView2」并配 Edge 图标的问题。音频实际由 WebView2 的音频服务子进程播放，该进程不带应用身份，系统只能按 exe 身份回退；现由应用在播放期间把属于自己的音频会话名称/图标改写为「AuralFlow + 应用图标」。
- 新增 `docs/desktop-volume-mixer-identity.md`：记录上述两个问题的排查证据、修复边界（只处理默认渲染端点等）。

## 下载与更新

- `windows-x64-setup.exe`：Windows x64 安装版（应用内自更新使用它）。
- `windows-x64-portable.exe`：Windows x64 便携版。
- `.sig`、`latest.json`、`latest-mirror.json` 为桌面更新签名和清单，普通用户无需单独下载。
- Android 最新仍为 v0.6.12；本版只包含桌面端修复，移动端更新入口在下一次 Android 发布时恢复。

## 验证边界

- Rust 侧 65 项测试（含缩略图尺寸解析、进程链判定）、桌面前端 434 项测试、共享核心 137 项测试全部通过；三处类型检查通过。
- 缩略图与音量合成器的**显示效果需要安装后人工确认**：自动化测试只覆盖尺寸解析、图标串、会话改写判定等纯逻辑，未覆盖 DWM 与系统音量面板的实际渲染。
