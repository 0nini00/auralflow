# AuralFlow v0.6.24 — Windows

播放列表与音源更新提醒的体验修复(用户实测反馈,headless Chrome 实测定位根因)。

## 修复

- **播放列表打开即定位当前曲,不再有滚动动画,也不再顶起页面布局**(沉浸式页面与
  底部迷你栏两处)。根因:面板定位当前曲用的是 `scrollIntoView`,这个 API 会连带滚动
  所有可滚动祖先——实测把沉浸页舞台整体顶上去 115px(控制栏 y 704→589、歌词区
  y 60→-55),且平滑模式下长队列的定位以动画呈现,表现为「白屏从底部上升挤压空间」
  和「明显的滚动动画」。现改为直接设置列表滚动位置:只滚列表本身、瞬时定位、零动画、
  布局零位移(实测修复后各区域与打开前逐像素一致)。
- **自定义音源更新弹窗不再频繁打开:不退出软件,每个音源只提示一次**。根因:脚本在
  每次播放/取链时都可能上报更新,且每次上报都会刷新更新检查时间戳,导致「今日不再
  提示」的记录永远匹配不上,于是每次播放都重弹。现增加会话级去重:同一音源本次启动
  只自动弹一次;设置页的「查看更新」按钮不受限,随时可手动打开。

## 验证

- 桌面前端 456 项测试通过(新增 3 项:更新弹窗会话去重与手动豁免);类型检查通过。
- 队列面板行为经 headless Chrome 实测(120 首队列、当前曲第 61 首):打开即定位、
  滚动位置恒定无动画、打开前后布局逐像素一致。

## 下载与更新

- `AuralFlow-v0.6.24-windows-x64-setup.exe`:NSIS 安装版(支持应用内自动更新)。
- `AuralFlow-v0.6.24-windows-x64-portable.exe`:便携版。
- 从 v0.6.23 及更早版本升级:安装版可直接「设置 → 检查更新」,或下载 setup.exe 覆盖安装。
