# AuralFlow v0.6.8

## 桌面功能

- 本地曲库新增全部、艺术家、专辑、文件夹分类与搜索，播放队列跟随当前筛选结果。
- 本地歌曲支持从网易云或 QQ 音乐搜索并预览歌词、封面，明确选择后默认只应用本机资料；写回音频文件需要单独确认。手动封面独立存储，不受自动缓存清理影响。
- 新增罗马音和注音显示开关，同时用于沉浸式与桌面歌词；只显示来源提供的数据，不自动生成。手动匹配保留译文与罗马音，本机词优先于自动缓存。
- 新增本地 ReplayGain 音量平衡，默认关闭，读取已有曲目增益与峰值标签；用户音量、静音和在线音频通路保持独立。

## 沉浸式播放

- 左侧封面下显示歌名、歌手和专辑，右侧滚动歌词，背景统一为柔和的封面环境色。
- 底栏使用细进度线和三段式控制区；主控件支持鼠标悬停、键盘聚焦与触屏显示。
- 更多菜单统一整理收藏/加入歌单、播放速度和复制歌曲链接。
- 保留逐字歌词、译文、罗马音、注音、队列、全屏、快捷键和现有播放能力；本版不加入频谱或均衡器。

## 可靠性与交互修复

- 修复搜索部分失败隐藏成功结果、私人 FM 失败后自动循环、歌单切换与刷新响应串线，保留已有结果并提供重试。
- 登录、退出与 WebDAV 设置增加事务和生命周期保护，修复验证失败卡住、旧保存覆盖新设置及清空配置不保存；账号歌单缓存按登录会话隔离。
- 取消链接导入不再继续创建歌单；下载区准确区分取消失败、原生文件完成与后处理，保留标签/歌词/封面失败警告。
- 全局快捷键避让交互控件，搜索联想支持键盘选择；统一弹窗焦点和 Escape 层级，支持关联的收藏/音质弹出菜单。
- 修复底栏拖动误跳、换歌后的旧手势、桌面歌词动作重复执行，以及歌词偏移与高亮时间不一致。

## Android

版本同步到 0.6.8（versionCode 16），提供 arm64-v8a 和 armeabi-v7a 正式签名包以保持共用 Release 更新入口完整。本轮没有新增移动端页面功能。

## 发布验证与边界

- 桌面前端、共享核心及 Rust 自动化测试，类型检查和正式构建纳入发布前验证。
- 已进行受控浏览器交互与真实音频信号验证；真实账号登录、正式云端同步以及原生安装后完整人工视听验收未替代为“已完成”。
- ReplayGain 依赖已有标签，缺少有效标签时不补偿；LX 开关是功能控制，不是脚本安全沙箱。已发出的远端请求不能撤回。
