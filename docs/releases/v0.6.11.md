# AuralFlow v0.6.11 — Windows

## 修复

- 修复沉浸播放队列在浅色主题下滚动条过亮的问题，使用固定的沉浸配色。
- 队列保留纵向滚动并阻止横向溢出。
- 队列右侧移除按钮的提示改为向上、右对齐，保留鼠标悬停及键盘焦点反馈。
- 更新相应界面规范；tooltip 配色仍沿用全局主题，本次没有更改队列播放或移除行为。

## 下载与更新

- `windows-x64-setup.exe`：Windows x64 安装版。
- `windows-x64-portable.exe`：Windows x64 便携版。
- `.sig`、`latest.json`、`latest-mirror.json` 为桌面更新签名和清单，普通用户无需单独下载。
- Android 更新单独发布为 v0.6.12；最终 Latest 同时保留本版桌面更新清单，双端更新入口互不覆盖。
