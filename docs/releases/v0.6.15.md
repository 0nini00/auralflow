# AuralFlow v0.6.15 — Windows

## 修复

- 修复沉浸式页面里进度条上方、下方各多出一条同色横线的问题。原因：进入沉浸页时焦点管理会把焦点交给进度输入框（`useDialogFocus` 的初始焦点就是它），而进度/音量轨道此前用 `:focus-within` 画焦点环（2px、外扩 5px）；那个输入框本身不可见、高 24px、横跨整行，焦点环的左右两边被裁掉后，只剩进度条上方与下方各一条横线，颜色又与进度条相同，看起来像多画了两条进度条。
- 现在两条轨道的焦点环改为**只在键盘聚焦时出现**（`:has(input:focus-visible)`）：打开沉浸页的程序聚焦、以及鼠标点击/拖动滑条都不再画环，键盘 Tab 导航时仍照常显示焦点环。

## 下载与更新

- `windows-x64-setup.exe`：Windows x64 安装版（应用内自更新使用它）。
- `windows-x64-portable.exe`：Windows x64 便携版。
- `.sig`、`latest.json`、`latest-mirror.json` 为桌面更新签名和清单，普通用户无需单独下载。
- Android 最新仍为 v0.6.12；本版只包含桌面端修复，移动端更新入口在下一次 Android 发布时恢复。

## 验证边界

- 桌面前端 417 项测试与类型检查通过；另外用最小复现页（逐字复制同一段 CSS 与结构）验证：修复前程序聚焦进度条时计算样式为 `outline: 2px solid rgb(237,244,229)`（即那两条横线），修复后程序聚焦与鼠标点击滑条两种情况都是 `outline: none`，键盘焦点环仍由 `:focus-visible` 决定。
- 沉浸页的实际观感需要安装后人工确认：自动化测试覆盖不到焦点环的渲染。
