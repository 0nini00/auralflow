# AuralFlow v0.10.2

自 v0.10.1 以来一轮**底层清理 + 新增能力**：新增两条音源能力（隐藏兜底音源、会员直连优先），并对全仓做了一次前后端分头审查，把发现的缺陷与冗余一次性扫完。桌面与 Android 同步到 0.10.2（Android versionCode **39**）。

## 新增 · 隐藏兜底音源（酷我 / 酷狗）

常规链路（内置网关、自定义音源、官方直连）全部失败后，按「歌名 + 首选歌手」到酷我、酷狗搜索同名曲目兜底。它**不是 UI 来源**：播放器、歌词、历史与列表里始终是你点的那首歌，只有音频 URL 来自隐藏平台。

- **搜索原生、取链交给脚本**：LX 用户脚本只实现 `musicUrl`/`lyric`/`pic`，本身不会搜索。所以搜索由 `@lx/core` 原生实现（`search.kuwo.cn` / `songsearch.kugou.com`），取链交给已启用、声明了 `kw`/`kg` 平台能力的脚本；没有对应脚本就不发起搜索。
- **宁可失败也不播错歌**：严格匹配（规整歌名相等 + 至少一位歌手重合 + 双方都有时长时差 ≤ 5s）。伴奏版本整体沉到人声版本之后，但不剔除——平台只收录伴奏时，能出声好过整首失败。
- **搜索与取链分离**：搜索是纯 HTTP，可以在常规链路运行期间提前并行；取链只在常规链路确认失败后才调脚本，1 秒就解析成功的歌不会白唤醒 LX 脚本。
- **候选先判死链**：脚本返回「成功」不等于地址可用，取链后先在候选内部发一次 1 字节 Range 探活，只有服务端明确 4xx 才换下一个；超时/抖动放行交给外层。

## 新增 · 会员直连优先

已登录会员会话里，把官方取链（weapi + Cookie）提到**主源位置**，失败再照常唤醒网关与自定义源。此前官方链路只排在全败后的兜底位，会员点一首歌仍要先走第三方网关，拿不到无损时听到的就是降档结果。开关由账号层在登录/退出/会员状态变化时写入，解析层只读；双端各一个无依赖模块。

## 新增 · 其他

- **移动端评论热门 / 最新**：两个标签页来自同一次请求——热门是接口附带的一页（不参与分页），最新按时间倒序可翻页。热门只在第一页取，避免翻页把用户正在看的热门覆盖掉。
- **音乐云盘曲目下载原文件**：云盘曲不做转码，请求哪档都是同一份上传文件，所以直接下载原文件（保留内嵌标签与歌词），不再弹音质菜单。

## 歌词

- 行定位算法（当前行计算 + 平滑推进）收敛到 core 的 `scheduleOverlayTick`，桌面与移动删掉各自的副本。
- 移动端带回**罗马音**副行，跟随译文开关，不新增开关粒度。
- 桌面端删掉 `localStorage` 歌词缓存——它会用过期歌词盖住新结果。

## 修复（按影响排序）

- **Rust 主线程重 IO**：媒体缓存统计/清理、曲库保存、`debug_log`、SMTC 更新都会在主线程上做磁盘 IO，大曲库或大缓存时会卡 UI。全部改 `async` + `spawn_blocking`；缓存写入的 `flush`+`rename` 也移入阻塞池。
- **qrc 歌词整首丢失**：`parseYrc` 的正则不接受「括号标记只有一个逗号」的明文形式，经 auto 判型后会解析出 0 行。改用宽容正则，补 3 例回归。
- **下载取消竞态**：取消一个还在排队（queued）的任务时未记录到 `cancelledTaskIds`，任务会被后续调度重新拉起。
- **移动端 `stopDownload` 未捕获异常**：底层抛错时状态卡在 `downloading`，该任务再也无法重试。
- **移动端保存封面 403**：缺 `UA` 被图床拒绝。
- **自定义源内层 deadline 漂移**：内层固定 10s，外层总预算变化时实际可用时间与预期不符；改为跟随剩余预算。
- **出站地址校验**：补拦 NAT64 前缀 `64:ff9b::/96`，此前可绕过内网判定。
- 其它：下载嗅探攒够 512 字节再判类型（跨 chunk）、重名超上限改为报错而非删旧文件、本地音频歌词标签写入按 `primary → first → 按类型新建` 回退、`audio_session` 的 `wcslen` 限长 4096、桌面歌词窗置顶状态改为内存镜像（拖动时不再每个事件读盘）。

## 清理

- **Rust**：删除 `hash_local_file` 整模块、`library_reset_all`/`reset_all`、`save_settings`/`reset_settings`（含 `config.rs` 两个函数）、`AppSettings` 三个窗口死字段，以及 bridge 里对应的封装与类型。
- **core**：删除 `createRacingBuiltinMusicApiClient`、`mergeMissingLines`；新增 `playback-budgets.ts`，把双端手抄的解析预算常量（2500ms / 10s / 1.6s / 并发 3）下沉并加 `withBudget`。
- **桌面**：`builtinMusicApiModel` 只保留桌面编排，逻辑复用 core（顺带找回 `mvId`）；托盘 / 歌词窗 / SMTC 三处播放分发合成 `playbackActions`；`withTimeout`、`formatBytes` 去重；删 `PactModal` 死 prop、`sleepTimerStore.totalMinutes`、孤儿样式。
- **移动**：`songKey` 六处副本统一到 `buildSongKey`；自定义源取链定时器、列表滚动补偿定时器补齐清理；删三个死导出。

## 行为调整

- **歌单广场（桌面 + 移动）去掉「热门 / 最新」分类**，固定热门排序。移动端「评论」的热门 / 最新保留。

## 升级

- 桌面端：覆盖安装即可，设置、曲库、自定义音源与下载记录全部保留。
- Android 端：直接覆盖安装（versionCode **39** > 38）。新增的隐藏兜底音源需要你已安装并启用声明了 `kw`/`kg` 平台能力的 LX 音源脚本，否则不会生效（也不会影响原有播放）。
