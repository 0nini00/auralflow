# AuralFlow v1.0.8

本次更新修复 Android 播放器背景恢复问题，并优化移动端播放列表与桌面端窄窗口布局。桌面与 Android 版本均为 1.0.8，Android versionCode 为 58。

## Android

- 修复切换歌曲、长时间后台播放后返回竖屏播放器时，柔光色域背景变黑的问题；视图恢复有效尺寸后重新绘制，并处理 WebView 渲染进程退出后的重建。
- 播放列表采用紧凑布局，强化当前播放歌曲与歌手信息层级；绿色仅作为播放状态和操作强调色，保留移除、清空和拖动排序。
- 下载弹窗适配底部安全区域，内容过长时可以滚动；歌单广场补足按钮点击区域，首页卡片与快捷入口文字更易读。
- 改善危险按钮文字对比度，歌词设置滑块补齐名称与数值说明。

## 桌面端

- 搜索结果按内容区实际宽度调整布局，修复窄窗口同时打开播放侧栏时歌名被挤掉、操作按钮压缩或溢出的问题。
- 键盘 Tab 聚焦搜索操作时显示按钮与焦点。
- 修复浅色、深色主题下危险确认按钮及其悬停状态的文字对比度。
- WebDAV 地址、用户名和密码关联可见标签，点击标签可以聚焦输入框。
- 桌面歌词 8 个滑块补齐名称与数值单位，基础开关补齐名称。

## 安装包

- Windows x64：安装版、便携版，附应用更新签名与更新清单。
- Android：ARM64、armeabi-v7a，使用现有正式签名证书。
- 随附对应版本源码、第三方声明和 SHA-256 校验清单。

## 验证

移动端 1181 项、桌面端 889 项、共享核心 456 项测试通过；双端类型检查与 lint、9 项发布源码绑定检查通过。

本次未连接 Android 设备进行安装与真机验收；桌面界面完成浏览器布局与键盘交互验证。
