# AuralFlow v0.10.1

自 v0.10.0 以来的一轮**可用性修复**：自定义音源可以拖着排序（移动端 + 桌面端），设置页行距与分段控件排版收口，播放页菜单去掉重复入口，队列面板反复开合的白屏问题补齐兜底。

## 自定义音源 · 拖拽排序（移动端 + 桌面端）

- **移动端**：音源卡片长按 320ms 抬起，上下拖动换位，松手才落库。卡片高度不固定（测试结果、更新提示、更新地址都会撑高），所以落位按相邻卡片中心的**中点**判断，拖过一半即换位；拖动中其余卡片按「被拖卡片实际高度 + 间距」让位。拖到视口上下 64px 内会按距离加速自动滚页，拖拽期间页面滚动被锁住，竖滑不会再被 ScrollView 抢走。
- **桌面端**：按住音源卡片即可拖动，按下后由 window 级指针监听接管，列表在拖动过程中不重排（避免抖动），松手才改顺序；原位松手不写库，卡片内的开关、按钮、「状态详情」保留原有点击行为。
- **键盘与读屏**：移动端卡片头部加了拖动手柄（`adjustable`，播报「第 N 项 / 共 M 项」，支持 increment/decrement）；桌面端手柄可聚焦，用上下方向键逐格移动。原来的上移/下移按钮在移动端保留给读屏操作，桌面端换成拖动手柄 + 方向键。
- **顺序即优先级**：音源换序后清空跨源命中缓存，避免换序后仍命中旧音源的解析结果。
- 新增纯计算模块：移动端 `services/sourceReorderModel.ts`，桌面端 `utils/listReorder.ts`——让「指针算出的槽位」和「store 里 remove→insert 的下标」共用同一套语义。

> 内部接口变更：桌面端 `customSourceStore.moveSource` 的参数从 `(id, "up" | "down")` 改为 `(id, targetIndex)`。

## 移动端 · 设置排版

- 「我的 → 服务与同步」三个并排按钮宽度随文案变化、窄屏会折行，改成与「设置」一致的 `SettingsRow` 图标行（音乐云盘 / 自定义音源 / WebDAV 同步，各带一行说明）。
- 歌词设置的「字体」三选项与「动效强度」三档原本按文字宽度排、右侧留空，改为 `flexBasis: 0` 三等分铺满卡片，描边 2px→1px，高度统一 44；字体卡补了「字体」行标题。
- `SettingsRow` 新增 `divider` 开关，组内最后一行不再与卡片底边叠成双线（我的两处卡片与设置首页四组同步处理）。

## 播放页 · 菜单收敛与白屏加固

- 「更多选项」移除「播放列表」：播放页底部已有常驻队列按钮，菜单里重复且要多开一层。队列每行的更多菜单移除「下一首播放」，只保留收藏到歌单 / 下载 / 播放 MV / 分享 / 从队列移除。
- 队列面板在沉浸屏内不再套 `GestureHandlerRootView`（沉浸屏本身已是手势根的子节点），只有落在独立原生窗口（RN Modal）时才自带 root，避免反复开合叠加 root。
- `QueueModal` 收起时复位 `subSheetOpen` 与三个子弹窗状态：此前若某次子弹窗未回调 `onClose`，下次打开会只剩一个没有列表的空面板。
- 播放页入场兜底：封面框 700ms 内测量不到时（转场永远不会启动）强制把整页恢复到可见态；打开任意覆盖层前也确保 `rootOpacity` 为 1，避免覆盖层收起后露出白页。

## 升级

- 桌面端：覆盖安装即可，自定义音源顺序会按新顺序保存；旧版本存下的顺序原样保留。
- Android 端：直接覆盖安装（versionCode **38** > 37），主题色、歌单与本地曲库数据保留。
