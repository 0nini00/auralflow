# AuralFlow UI 细节对比 — 按钮/文案/布局

> 2026-07-10，逐行比对桌面端和移动端的 UI 元素

---

## 1. 首页 Home

| 元素 | 桌面端 | 移动端 | 问题 |
|---|---|---|---|
| 标题文案 | Hero: eyebrow "AuralFlow" + h1 "发现音乐" | 顶部 section "发现音乐" + hero 卡片又是 "发现音乐" | **重复标题**，移动端出现了两次"发现音乐" |
| Hero 副文案 | "从搜索、本地曲库和私人 FM 开始，把想听的歌快速接到播放队列里。" | 同 | ✅ 一致 |
| Hero 按钮 | 2 个：「私人 FM」「搜索音乐」（图标+文字按钮） | 3 个发现卡片：「每日推荐」「私人 FM」「搜索音乐」 | 移动端多了「每日推荐」卡片，布局是 2+1 网格 |
| 最近播放标题 | "最近播放" | `songActions.title`（动态） | 需确认动态值是否也是"最近播放" |
| 操作按钮 | "播放全部" | "播放全部" + "查看全部" | 移动端多了「查看全部」跳曲库历史 |
| 最近播放列表 | `MusicCard` 网格（大封面卡） | `SongList` 列表行 | 展示形式不同，合理 |
| 空态文案 | "还没有播放过歌曲" + "搜索并播放一些音乐后，这里会显示你的最近播放。" | `songActions.emptyCaption` / `songActions.emptyText` | 需确认文案是否一致 |
