## 保留的边界

当前没有连接 ADB 设备，未安装或进行真机 FPS、触摸延迟、Hermes CPU/GPU 测量；Node 数字不能当作手机实测。新增脚本运行时池的第三方脚本兼容性也需实际使用确认。

统计为兼容现有消费者仍对 events 数组做 O(N) 引用浅复制；首次启动仍需加载历史并建立索引。分组按歌名缩小候选范围，但大量同名不同版本的最坏情况仍需组内比较。QQ 元数据补全是具有独立四秒期限的共享请求，取消播放只取消该消费者的等待，不破坏其他消费者。

RNFS 重定向期限补丁绑定已安装的 2.20.0；依赖升级时会明确报错要求重新核验，不能悄悄跳过补丁。桌面的旧软调度通过显式 mode 保持兼容，移动端使用真实严格并发和请求级取消。
