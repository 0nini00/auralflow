# 沉浸播放页布局优化设计

## 目标

修复桌面端沉浸播放页歌曲信息位置、封面垂直节奏和歌词滚动视觉层级问题，同时保持播放器 Store、全屏、快捷键、队列和桌面歌词行为不变。

## 已确认设计

- 歌曲信息独立为顶部居中标题区，共两行：第一行为歌名，第二行为歌手。
- 主体继续采用左封面、右歌词的双栏结构；封面相对当前布局下移，使视觉中心与歌词当前行区域协调。
- 歌词保持居中对齐。
- 当前歌词锚定在歌词视口约 38% 高度，采用与 lx-music-desktop 相同的偏上视觉焦点。
- 当前行高亮并轻微放大，临近行可读，远端行依靠透明度和上下渐隐弱化。
- 相邻换行继续平滑滚动，seek 和非相邻跳转立即定位，手动滚动三秒后恢复。

## 结构


default immersive root
├── top heading: song title / artist
├── stage
│   ├── cover section
│   └── scrolling lyrics section
└── playback controls

标题不再放在封面下方，避免封面与元信息共同挤压主体高度。标题区位于窗口标题栏下方，并独立参与整体纵向布局。

## 约束

- 不修改路由名、Zustand Store API、Tauri command 名称和 Android Bridge。
- 不增加歌词点击跳转、时间标尺或新的播放功能。
- 不改变现有键盘控制、全屏退出所有权、队列和桌面歌词按钮逻辑。
- 不覆盖或回退工作区中已有修改，不创建提交。

## 验收

- 常规窗口和原生全屏下，歌名与歌手均在顶部居中完整显示，不与标题栏重叠。
- 封面比当前版本更靠下，且不遮挡底部控制栏。
- 当前歌词稳定显示在右侧视口约 38% 高度，首行和末行可正确钳制。
- 当前行、相邻行和远端行层级清晰，歌词保持居中。
- 桌面测试、类型检查、生产构建和 Tauri 打包通过。
