# 桌面 LX 自定义音源总开关

## 用户行为

设置的音源页始终保留“启用 LX 自定义音源”。新安装及旧版空源列表默认关闭；旧数据缺少 featureEnabled 且已有音源时迁移为开启。已保存的 false 不受源数量影响。关闭后保留脚本、排序及逐源启用设置；内置网易云、QQ、本地播放和普通歌单同步继续工作。当前已经播放的歌曲和已经开始的下载不强行中断。

总开关只属于本机 customSources 命名空间。云端音源同步文件不包含它，下载源列表不能更改它。关闭时禁止源管理、取链、预加载、测试、更新检查及音源专属同步，音源更新弹窗隐藏。

## 实现不变量

- customSourceStore.featureEnabled 是唯一持久化开关，featureReady 表示初次加载完成。
- customSourceAccess 从 store 的 getter 读取许可，仅保存操作代际及 AbortController，不维护第二份开关。每次切换使旧操作永久失效，即使关闭后马上开启也不能接受旧结果。
- 运行时通过参数接收 CustomSourceOperation，避免运行时反向硬依赖 store。
- 内存预取和持久化播放缓存保留 backend，停用时排除 customSource 结果；原生音频缓存按 backend 分区。新的媒体 lookup/写入不复用旧 key；历史持久化条目仍按 backend 判断，不追溯或删除用户已有文件。
- 同步在网络请求和本地替换之前核对原令牌，绝不以清空源列表代表停用。关闭时取消整个音源同步流程的应用侧等待，包括配置读取、网络、响应体及解压阶段。音源与普通同步分别互斥；旧音源请求未实际结束前仍保留音源互斥，防止重开后远端 PUT 乱序覆盖，但不阻塞普通歌单同步。
- 显式保存失败向界面传播，后台保存失败继续落日志并保留待重试快照。同一命名空间串行写入；加载失败禁止开启和导入；仅就绪状态变化不重写持久化数据。

## 安全与取消边界

这是功能控制，不是脚本安全沙箱。脚本依然在主 WebView 通过 new Function 执行，任意脚本逃逸后创建的副作用不受此开关强制终止。受管等待、更新监听及初始化定时器可释放；已发送到 Rust 的网络或远端 PUT 请求不能撤回，不保证服务端未收到请求。关闭后不再发出新的受管操作，迟到响应不进入源列表、缓存或播放。

## 自动验证

pnpm test:desktop 覆盖状态迁移、真实 React 界面/effect、运行时初始化与在途请求、同步提交边界、预取与持久化缓存、媒体缓存和播放器接管边界。pnpm test:core、pnpm desktop:typecheck、pnpm desktop:build 分别验证共享逻辑、类型与桌面前端构建。桌面测试已加入 test:all 与 CI。
