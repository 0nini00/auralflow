# 桌面端全屏歌词滚动设计

## 目标

在保留 AuralFlow 现有播放时间插值、歌词当前行判定和逐字高亮能力的前提下，为桌面端沉浸播放页增加完整歌词列表、LX 式自动滚动、用户手动浏览恢复、键盘控制和可靠的 Tauri 全屏状态同步。

## 结构

- `ScrollingLyricsVisualizer.tsx`：完整歌词列表、当前行样式与 DOM 行引用。
- `useLyricAutoScroll.ts`：滚动动画、指针拖动、滚轮接管、3 秒恢复和 ResizeObserver 重定位。
- `autoScrollModel.ts`：纯状态机和滚动位置计算，承载单元测试。
- `immersiveKeyboard.ts`：纯键盘动作映射。
- `useNativeFullscreen.ts`：Tauri 全屏查询、窗口事件同步、切换和所有权清理。

## 行为

1. 当前行固定在歌词视口约 42% 高度，首尾位置钳制到合法范围。
2. 连续前进一行时延迟 600ms，并用 600ms easeInOutQuad 动画滚动。
3. seek、切歌、后退或跨多行跳转立即定位。
4. 滚轮或指针拖动开始后取消自动动画，停止操作 3 秒后回到最新当前行。
5. 窗口尺寸、歌词字号、字体或译文显示导致布局变化时重新定位。
6. 空格、方向键、Shift+左右、M 和 Escape 在沉浸页内可用。
7. 全屏按钮状态由 Tauri 窗口真实状态驱动；仅当沉浸页主动进入全屏时，关闭沉浸页才自动退出全屏。

## 非目标

- 不复制 LX 将 DOM 节点保存到状态层的实现。
- 不替换现有歌词解析、播放时钟和逐字进度算法。
- 不修改独立桌面歌词窗口。

## 验证

- Vitest：相邻换行、seek 跳转、手动滚动恢复、首尾钳制、重定位和键盘映射。
- TypeScript 类型检查。
- Vite 生产构建。
