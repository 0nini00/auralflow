# AuralFlow Android 播放体验移动端优化设计文档

| 项目 | 内容 |
|---|---|
| 日期 | 2026-07-31 |
| 目标 | 参考 lx-netease-music-mobile，将播放引擎、沉浸式播放、播放控制从桌面端移植风格改造为移动端原生体验 |
| 影响范围 | `apps/mobile`（React Native 端） |
| 采用方案 | 滑动切换封面/歌词 + 控制区极简 + 播放引擎弱化音效 + 手势化交互 |

---

## 1. 背景与问题

当前移动端播放相关功能存在较浓的桌面端移植痕迹：

- **沉浸式播放页控件过载**：`ImmersiveTransport` 的 auxRow 一排 11 个按钮（喜欢/加歌单/分享/音量/倍速/音效/睡眠/队列/翻译/海报/隐藏控制），小屏手机上横向滚动或换行，操作繁琐。
- **歌词/封面切换不自然**：手机端用"点击展开两行歌词"（PosterMode），而不是左右滑动切换，不符合移动端手势习惯。
- **播放控制区信息密度过高**：进度条+时间+封面+标题+播放模式+上一/下一+播放+队列，挤在一行或两行。
- **音效功能在移动端无意义**：Android 原生不支持 pitch（变调），EQ/混响音效在手机扬声器上效果微弱，且增加复杂度。
- **缺少手势交互**：没有滑动切换封面/歌词、没有上滑打开播放列表、没有双指缩放歌词字号。

本设计的目标是在**保留核心功能**的前提下，让播放体验更符合移动端手势习惯，操作更简洁。

---

## 2. 设计目标

| 目标 | 描述 |
|---|---|
| 手势化 | 用滑动代替点击，符合移动端操作习惯 |
| 极简化 | 控制区只保留高频按钮，低频功能收进菜单 |
| 本地化 | 参考网易云音乐等主流移动端播放器交互 |
| 兼容性 | 不影响桌面端代码，不改变后端 API |

## 3. 沉浸式播放页重新设计

### 3.1 整体布局对比

**当前布局**：
```text
┌─────────────────────────────────────┐
│  [关闭]  歌名-歌手  [海报模式]      │  ← ImmersiveTopBar
├─────────────────────────────────────┤
│                                     │
│         封面 / 海报模式             │  ← ImmersiveStage (手机点击切换)
│        (点一下展开两行歌词)         │
│                                     │
├─────────────────────────────────────┤
│  进度条                             │  ← ImmersiveTransport
│  [模式] [上一] [播放] [下一] [队列]  │
│  [喜欢] [加歌单] [分享] [音量] ... │  ← 11个aux按钮，小屏放不下
└─────────────────────────────────────┘
```

**lx 参考布局**：
```text
┌─────────────────────────────────────┐
│  [关闭]  歌名-歌手  [设置]          │  ← Header
├─────────────────────────────────────┤
│                                     │
│         封面 ← → 歌词              │  ← PagerView 滑动切换
│        (左右滑动，不是点击)         │
│                                     │
├─────────────────────────────────────┤
│  ────────────进度条───────────────  │  ← PlayInfo (极简)
│  [模式] [上一] [播放] [下一] [更多]  │  ← ControlBtn + MoreBtn
└─────────────────────────────────────┘
```

**优化后布局**：
```text
┌─────────────────────────────────────┐
│  [关闭]  歌名-歌手  [设置]          │  ← ImmersiveTopBar (保留)
├─────────────────────────────────────┤
│                                     │
│         封面 ← → 歌词              │  ← PagerView 左右滑动切换
│        (歌词页双指缩放字号)         │
│                                     │
├─────────────────────────────────────┤
│  ────────────进度条───────────────  │  ← ProgressBar (细线)
│  [模式] [上一] [播放] [下一] [更多]  │  ← 主控制行 (5个按钮)
└─────────────────────────────────────┘
```

### 3.2 封面页改动

| 项目 | 当前 | 改为 |
|---|---|---|
| 封面展示 | PosterMode（点击展开歌词） | 独立封面页 + MiniLyric（底部小歌词条） |
| 封面旋转 | 无 | 可选旋转唱片风格（25s/圈，播放时转，暂停停转） |
| 封面尺寸 | 固定比例 | 自适应 `min(width*0.85, (height-statusbar-header)*0.5)` |
| 长按操作 | 无 | 长按封面弹出菜单（下载歌曲/下载封面） |

### 3.3 歌词页改动

| 项目 | 当前 | 改为 |
|---|---|---|
| 歌词显示 | FlatList（ITEM_HEIGHT=68） | FlatList + 逐行动画滚动（viewPosition: 0.42） |
| 歌词交互 | 点击行 seek | 点击行 seek（可配置开关） + 双指捏合缩放字号 |
| 歌词滚动 | 瞬时跳转 | 逐行平滑滚动，手动滚动后 3 秒恢复自动 |
| 歌词字号 | 固定 | 双指缩放，范围 100-300，持久化到设置 |
| 翻译显示 | 无 | 支持翻译行（extendedLyrics） |

### 3.4 封面/歌词切换手势

- 使用 `react-native-pager-view` 实现横向翻页
- 封面页在左，歌词页在右，**左右滑动切换**
- 切到歌词页时 `screenkeepAwake()` 保持屏幕常亮
- 切回封面页取消屏幕常亮
- 歌词页加载优化：仅在切到歌词页时才渲染歌词组件（lx 的 LyricPage 模式）

### 3.5 控制区精简

**主控制行**（保留）：
- 播放模式（list/single/shuffle/sequence）
- 上一首
- 播放/暂停
- 下一首
- 更多（MoreBtn）

**MoreBtn 菜单**（收进弹层）：
- 喜欢/收藏
- 加入歌单
- 分享
- 音量控制
- 倍速播放
- 音效设置
- 睡眠定时
- 播放列表
- 翻译开关
- 海报模式开关

## 4. 播放控制区精简（PlayerBar）

### 4.1 当前 vs 优化后

**当前 PlayerBar**：
```text
┌─────────────────────────────────────┐
│  [封面] 歌名-歌手                   │
│  ════════════进度条═══════════════  │
│  [喜欢] [播放] [下一首] [⋯]         │
└─────────────────────────────────────┘
```

**lx PlayerBar**：
```text
┌─────────────────────────────────────┐
│  ════════════细进度条═════════════  │  ← 顶部细线
│  [封面] 歌名-歌手 [播放/暂停] [菜单] │
└─────────────────────────────────────┘
```

**优化后 PlayerBar**：
```text
┌─────────────────────────────────────┐
│  ════════════细进度条═════════════  │  ← 顶部细进度条
│  [封面] 歌名-歌手 [播放/暂停] [菜单] │
└─────────────────────────────────────┘
```

### 4.2 具体改动

1. **进度条位置**：从中间移到顶部细线（`MiniProgressBar`），只显示进度，不显示时间。
2. **控制按钮**：从"喜欢/播放/下一首/⋯"简化为"播放/暂停/菜单"，喜欢和下一首收进菜单。
3. **手势支持**：
   - **上滑**：打开播放列表面板
   - **长按**：跳转当前歌曲所在列表位置
   - **键盘弹出**：整条隐藏（useKeyboard）
4. **圆角样式**：顶部圆角（borderTopLeftRadius/RightRadius 6），提升悬浮感。

## 5. 播放引擎优化

### 5.1 音效功能弱化

| 项目 | 当前 | 改为 |
|---|---|---|
| EQ 音效 | soundEffectService 5 段 EQ | 保留实现，UI 入口收进 MoreBtn 菜单 |
| 混响效果 | PresetReverb | 保留实现，UI 入口收进 MoreBtn 菜单 |
| 变调 (pitch) | Android 原生不支持 | 隐藏 pitch 控件（UI 保留但 disabled） |
| 倍速播放 | 支持 | 保留，UI 入口收进 MoreBtn 菜单 |

**理由**：Android 原生不支持 pitch（`SoundEffectService.java` 返回 false），EQ/混响在手机扬声器上效果微弱，且增加复杂度。参考 lx 实现，移动端只保留音量控制。

### 5.2 锁屏控制

lx 通过 RNTP 自带的 Remote 事件实现锁屏控制（播放/暂停/上一/下一）。当前 auralflow 已有 `playbackService.ts` 监听 Remote 事件，无需改动。

### 5.3 播放列表手势

lx 的 PlayerPlaylist 从 PlayerBar 上滑或菜单打开。当前 auralflow 的播放列表从 Transport 的队列按钮打开，改为从 PlayerBar 上滑手势打开，保持菜单入口。

## 6. 手势交互总结

| 手势 | 位置 | 行为 |
|---|---|---|
| 左右滑动 | 沉浸式播放页封面区域 | 切换封面/歌词页 |
| 双指捏合 | 歌词页 | 缩放歌词字号（100-300） |
| 点击歌词行 | 歌词页 | seek 到该行时间点 |
| 上滑 | PlayerBar | 打开播放列表面板 |
| 长按 | PlayerBar 左侧 | 跳转当前歌曲所在列表位置 |
| 长按 | 沉浸式播放页封面 | 弹出菜单（下载歌曲/下载封面） |
| 下滑 | 沉浸式播放页顶部 | 关闭播放页（ChevronDown） |
