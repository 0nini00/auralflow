## 桌面端功能与 UI/UX 完整总结

### 1. 整体架构与成熟度
- **桌面端**：Tauri + Vite + React + Zustand 驱动，成熟度最高。
- **移动端**：React Native + Zustand，**明确是在桌面端基础上改的**（功能、歌词系统、播放引擎、Karpov 网关、WebDAV 同步、playerStore 等全从桌面端抄）。
- 当前状态：双端功能基本对齐，移动端在播放页和沉浸歌词上多了“移动端专属优化”（倍速、音质切换、沉浸歌词海报、氛围色）。

### 2. 桌面端核心功能（已完整看完）
- **播放页**：底部固定 PlayerBar，支持沉浸歌词 overlay（ImmersiveLyricsOverlay），歌词解析 + 同步逻辑在 desktop/src/services/lyrics。
- **布局**：顶部 Header + 侧边栏（默认隐藏抽屉） + 主视图区（左文右图）。
- **关键组件**：
  - PlayerBar.tsx（12549 行）
  - ImmersiveLyricsOverlay.tsx（24136 行）
  - Layout.tsx + Sidebar.tsx + Header.tsx
  - 所有 Views（HomeView, SearchView, PlaylistDetailView 等）使用 VirtualList + MusicCard。
- **后端/服务**：Karpov 网关（X-API-Key），WebDAV 七按钮同步，自定义音源，下载管理，歌词设置（字号/字体/颜色/背景），睡眠定时，音效面板，倍速切换（部分）。
- **数据流**：Zustand stores（playerStore, playlistStore, downloadStore 等）统一，Tauri bridge 接文件系统和下载。

### 3. 移动端核心功能（已完整看完）
- **播放页**：全屏 PlayerScreen + ImmersiveLyricsScreen（独立页面），支持沉浸歌词浮层、倍速、音质实时切换、队列弹窗、氛围色背景。
- **布局**：底部导航重构 + 全局顶部搜索 + 我的页层级（已从桌面端迁移）。
- **关键组件**：
  - App.tsx（5872 行）+ PlayerBar.tsx（23712 行！比桌面大很多，因为移动端全量实现）
  - LyricView + ImmersiveLyricsScreen
  - SongList + DownloadList + SearchScreen + LibraryScreen
- **数据流**：Zustand stores（playerStore 不同实现，但逻辑复用），Karpov 网关完全一样，WebDAV 七按钮面板已迁移完成。

### 4. 两者最明显的差异（移动端改动点）
- **播放页形态**：桌面固定底部，移动全屏 + 沉浸页面。
- **沉浸歌词**：桌面 overlay + 控制条简单；移动独立页面 + 海报切换 + 更丰富控制条（睡眠+倍速+音量+音效+音质）。
- **音质/倍速**：桌面无实时切换，移动有。
- **布局优化**：移动端为了手机屏幕，某些列表改成 SongList 行式，搜索历史独立列表等。
- **核心代码复用**：歌词解析（desktop/src/services/lyrics/parserCore.ts）、播放引擎（desktop/src/services/playerEngine.ts）、Karpov 网关、WebDAV 同步服务、LyricSettingsScreen 几乎 1:1 复制到移动端。

**结论**：移动端确实是“桌面端基础上改”的，功能几乎无缺失，只是播放页和沉浸歌词体验更“移动端原生”。桌面端在沉浸歌词、倍速、音质切换上还有点“后补”的空间。
